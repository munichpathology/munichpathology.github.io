## References on the Website

The website shall list references of your work in the section "[Publications](https://munichpathology.ai/#publications)". To add a new reference:

1. Login to Zotero (<https://www.zotero.org/> or Zotero app)  
   (if you don't have an account, register for a free account)
2. Go to the Group MCCP  
   (if you don't see this group, ask Peter to be invited)
3. Add the reference via DOI using the wand tool:
  <img src="images/wand.png" width="80" alt="wand tool">

It will then automatically be synchronized and added to the website.
